## 🌟 Overview / جائزہ

یہ پروجیکٹ **TECHNO** برانڈ کے لیے ایک مکمل، ہائی اینڈ اور پرفیکٹ شاپائفائی ای کامرس اسٹور ہے۔ اس میں آپ کے تمام مطلوبہ 15 اہم صفحات (Main Pages, Cart, Checkout, Policies, Tracking) مکمل ڈیزائن اور فنکشنلٹی کے ساتھ شامل ہیں۔ 

اس پروجیکٹ میں آپ کے لیے دو بنیادی چیزیں تیار کی گئی ہیں:
1. **مکمل انٹرایکٹو لائیو اسٹور (Interactive Web App & GitHub Pages Ready)**: 
   - مکمل کلائنٹ سائیڈ راؤٹر (Client-Side Router)
   - انٹرایکٹو کارٹ ڈراور (Slide-out Cart Drawer) اور فل کارٹ پیج
   - شاپائفائی اسٹائل چیک آؤٹ (Shopify 3-Step Checkout with Shop Pay / Card simulation)
   - ریئل ٹائم لائیو آرڈر ٹریکنگ (Track Order with Telemetry Timeline)
   - لائیو سرچ، ملٹی کرنسی کنورٹر (USD, EUR, GBP, CAD, PKR, AED)، اور کوپن کوڈز (`TECHNO15`)
2. **شاپائفائی پروڈکٹ امپورٹ CSV فائل (`techno_shopify_products_export.csv`)**:
   - آفیشل شاپائفائی فارمیٹ جس میں تمام 12+ پراڈکٹس، ویریئنٹس (Matte White, Stealth Black, Space Gray)، ہائی ریزولوشن تصاویر، HTML تفصیلات، SKUs، بارکوڈز، اور قیمتیں شامل ہیں۔ آپ اسے براہِ راست شاپائفائی ایڈمن میں امپورٹ کر سکتے ہیں۔
3. **مکمل شاپائفائی 2.0 تھیم سٹرکچر (`shopify-theme/`)**:
   - `theme.liquid`, `main-product.liquid`, `header.liquid`, `footer.liquid`, `bundle-section.liquid`, `templates/index.json`, `templates/product.json` وغیرہ۔

## 🚀 How to Run & Preview Locally / لوکل سسٹم پر چلانے کا طریقہ

آپ اس فولڈر کو کسی بھی براؤزر میں براہ راست کھول سکتے ہیں:
1. `index.html` فائل پر ڈبل کلک کریں اور کسی بھی براؤزر (Chrome, Edge, Firefox) میں اوپن کریں۔
2. یا لوکل سرور چلائیں (مثلاً Python یا Node):
```bash
# Python سے لوکل سرور چلانے کے لیے:
python -m http.server 8080

# یا Node npx سے:
npx serve .
```
براؤزر میں `http://localhost:8080` کھولیں۔ آپ تمام 15 پیجز، کارٹ، چیک آؤٹ اور ٹریکنگ باآسانی ٹیسٹ کر سکتے ہیں۔

## 🐙 How to Upload to GitHub & Deploy to GitHub Pages / گٹ ہب پر اپ لوڈ اور لائیو کرنا

آپ اس پورے فولڈر کو گٹ ہب پر اپ لوڈ کر کے 1 منٹ میں لائیو ویب سائٹ بنا سکتے ہیں:

### مرحلہ 1: گٹ ریپوزٹری بنائیں
```bash
git init
git add .
git commit -m "Initial commit of TECHNO Flagship Shopify Store with 15 pages and products CSV"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/techno-shopify-store.git
git push -u origin main
```

### مرحلہ 2: GitHub Pages ایکٹو کریں
1. گٹ ہب پر اپنی ریپوزٹری کی **Settings** میں جائیں۔
2. بائیں جانب **Pages** پر کلک کریں۔
3. **Branch** کے تحت `main` منتخب کریں اور `/ (root)` سلیکٹ کر کے **Save** دبائیں۔
4. آپ کی مکمل ویب سائٹ چند سیکنڈ میں لائیو ہو جائے گی:
   `https://YOUR_USERNAME.github.io/techno-shopify-store/`

## 📦 How to Import Products CSV into Real Shopify Admin / شاپائفائی میں پروڈکٹس امپورٹ کرنے کا طریقہ

ہم نے شاپائفائی کے آفیشل معیارات کے عین مطابق `techno_shopify_products_export.csv` تیار کی ہے:

1. اپنے **Shopify Admin** لاگ ان کریں (`https://admin.shopify.com/store/YOUR-STORE`).
2. بائیں مینو میں **Products** پر کلک کریں۔
3. اوپر دائیں جانب **Import** بٹن پر کلک کریں۔
4. **Add file** پر کلک کریں اور اس پروجیکٹ کی فائل `techno_shopify_products_export.csv` سلیکٹ کریں۔
5. **Upload and continue** دبائیں اور پھر **Import products** پر کلک کریں۔
6. تمام پراڈکٹس بشمول تصاویر، ٹائٹلز، قیمتیں ($199 وغیرہ)، کلر ویریئنٹس (Matte White, Stealth Black, Space Gray) اور ٹیگز خود بخود آپ کے شاپائفائی اسٹور میں شامل ہو جائیں گے!

## 🎨 How to Use the Shopify Theme / شاپائفائی تھیم انسٹال کرنے کا طریقہ

اگر آپ شاپائفائی کے اندر براہ راست ہماری ڈیزائن کردہ تھیم اپ لوڈ کرنا چاہتے ہیں:
1. `shopify-theme` فولڈر کا زپ (zip) فائل بنائیں۔
2. شاپائفائی ایڈمن میں **Online Store ➔ Themes** میں جائیں۔
3. **Add theme ➔ Upload zip file** پر کلک کریں۔
4. تیار شدہ زپ فائل منتخب کر کے اپ لوڈ کریں۔
5. آپ کے شاپائفائی سٹور پر TECHNO تھیم فعال ہو جائے گی!
